# STE Word Substitutions

Banned word/phrase → approved replacement. Based on the ASD-STE100 dictionary principle: prefer the short, common word with one meaning. Technical names and exact system terms always override this table.

## Verbs

| Do not write | Write |
|---|---|
| utilize, leverage | use |
| commence, initiate | start |
| terminate, cease | stop, end |
| perform, carry out, execute (a task) | do (or the direct verb: check, run, test) |
| accomplish | do, complete |
| attempt | try |
| ensure, make sure | make sure (procedures: state the check as a step) |
| verify (loosely) | make sure, check (keep "verify" only if it is the precise term) |
| obtain, acquire | get |
| require | need, must have |
| provide (a value) | give, supply, enter |
| implement (non-code sense) | do, install, set up |
| facilitate | help, make possible |
| enable X to Y (loosely) | let X Y (keep "enable" for feature flags/settings) |
| modify, alter | change |
| assist | help |
| indicate | show |
| observe | see, look at |
| select (a physical thing) | choose, click (keep "select" for UI selection if consistent) |
| transmit | send |
| construct | build, make |
| endeavor | try |
| retain | keep |
| demonstrate | show |
| ascertain, determine (find out) | find, find out |

## Nouns and phrases

| Do not write | Write |
|---|---|
| functionality | function, feature |
| in order to | to |
| prior to | before |
| subsequent to, following (prep.) | after |
| in the event that | if |
| at this point in time, currently | now (or delete) |
| a number of, various | some, or the exact number |
| additional | more |
| approximately | about (or the exact value) |
| assistance | help |
| in conjunction with | with |
| with regard to, regarding | about, for |
| due to the fact that | because |
| on a daily basis | daily, every day |
| has the ability to, is able to | can |
| it is recommended that you | we recommend that you (descriptive) / just give the instruction (procedures) |
| it should be noted that | Note: (or delete) |
| please note | Note: |
| as well as | and |
| in most cases | usually (or quantify) |
| adequate, sufficient | enough (or the exact amount) |
| optimal | best |
| numerous | many |
| component (loosely) | part (keep "component" if it is the technical name) |
| methodology | method |
| utilization | use |

## Hedges and vagueness (delete or make concrete)

| Do not write | Write |
|---|---|
| should (in a procedure) | must, or the plain imperative |
| may want to, might consider | (decide: either instruct it or omit it) |
| simply, just, easily, basically | (delete — if it were simple, the reader would not be reading) |
| appropriate, relevant, applicable | name the actual thing |
| as needed, if necessary | state the condition: "if X, then…" |
| shortly, soon, quickly | the actual time or the observable signal |
| large, small, many, few (unquantified) | the number or threshold |
| etc. | "for example, A and B" or complete the list |
| and/or | "A, B, or both" |
| i.e. | that is |
| e.g. | for example |

## Words with one fixed meaning (pick and hold)

- **close** — verb only ("Close the connection"). For proximity, write "near".
- **follow** — "come after" only. For compliance, write "obey" / "use" ("Obey the safety rules", "Use the steps in section 2").
- **check** — "examine" only. For "stop/restrain", use "stop".
- **right** — direction only. For correctness, write "correct".
- **once** — "one time" only. For sequence, write "when" or "after" ("When the job completes…", not "Once the job completes…").
- **since** — time only ("since v2.1"). For causation, write "because".
- **while** — time only ("while the worker runs"). For contrast, write "but" or "although" → prefer restructuring.
- **as** — comparison only. For time write "when"; for causation write "because".
