## Welcome

This reference documents the Blaaiz Platform external API endpoints used by businesses integrating with API Services.

## Authentication

All external endpoints are authenticated using OAuth 2.0 client credentials.

1. Generate your OAuth credentials from the Blaaiz dashboard.
2. Exchange them at `POST /oauth/token`.
3. Use the returned access token as `Authorization: Bearer <token>`.

Legacy API key creation is disabled, and legacy API key support will end soon. New integrations should use OAuth only.

```json
"security": [
  {
    "oauth2ClientCredentials": [
      "business-api-services"
    ]
  }
]
```
